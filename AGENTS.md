# Interface content rules

- Do not add eyebrow text, kicker text, overlines, or small labels before page or section headings.
- Do not add decorative labels inside content blocks or callouts. Examples include `Introduction`, `Lesson 01`, and `Course outcome` when they repeat nearby context.
- Do not add a heading or label above a navigation group when the links already make its purpose clear. Examples include `Course contents` and `Navigation`.
- Start each page or section with its primary heading when a heading is present.
- Add a navigation label only when the navigation would be ambiguous or inaccessible without it.
- Structure each course page or course section in this order: primary heading, descriptive subheader, then main content.
- Use a normal paragraph after the heading for the descriptive subheader. Do not style it as an eyebrow, kicker, overline, or label.
- Give every course parent page and subpage its own route. Course navigation links must navigate between routes instead of scrolling to sections on one long page.
- Show subpage links indented below their parent page in the course navigation.
