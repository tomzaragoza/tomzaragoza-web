# Set up your analytics

The instructional draft is implemented at `/x-ads/analytics` in `app/x-ads/course-data.ts`.

## Lesson sequence

1. Install and verify session replay using PostHog or Microsoft Clarity.
2. Trace a test visit through analytics and replay.
3. Save the X Ads metrics view.
4. Verify Search Console and record available brand-search data.
5. Complete the readiness checks.

Trackable links are deferred to the creating-ads lesson. See [saved draft](x-ads-trackable-links.md).
