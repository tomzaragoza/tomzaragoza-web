# Set up your X Ads account

The lesson is implemented at `/x-ads/account` in `app/x-ads/course-data.ts`.

## Lesson sequence

1. Prepare the profile used for advertising.
2. Get the blue checkmark through Premium.
3. Create the ads account.
4. Add and verify the payment method.
5. Check account readiness before tracking and campaign setup.
